# 낚시터 리디자인 검토

사용자 요청: 크림색 위주의 작은 마을 대신 넓은 낚시터, 귀엽고 짧은 캐릭터와 캐릭터 물고기, 페이지와 모달별 시안.

내장 ImageGen으로 만든 **동일 방향의 최종 13개 화면**이다. 원본 생성과 검수 교정 프롬프트는 prompts.json에 보존한다. 생성 이미지이며 실행 중인 화면 캡처가 아니다. 게임에 시안을 통째 배경으로 붙이거나 기능 구현 완료로 간주하지 않는다.

index.html을 브라우저에서 열어 순서대로 검토할 수 있다. 새 맵은 6144×4096 월드 단위, 기존 대비 면적 4배를 제안한다. 현재 게임 맵 크기는 아직 3072×2048이다.

자연형 물가, 연못·강·큰 호수, 양쪽 땅과 연결된 다리, 잔교와 물가 낚시 자리, 작은 미끼 가판을 중심으로 한다. 크림색 포장 광장 대신 좁은 회색 자갈길, 청록 수면·깊은 숲·목재·남청색 패널을 사용한다. 실제 캐릭터/월드/장비/이펙트 레이어와 충돌 경로를 각각 제작·연결해야 이 품질의 플레이 가능한 결과가 된다.

표시된 인원·보유량·순위는 예시다. 기본/숙련/명인 낚싯대와 1~3/4/5성 제한, 3/15/50/120 코인 미끼 가격과 20/60/160/550/2500 코인 판매 가격을 기준으로 교정했다. 모든 이미지의 작은 글자·별 개수가 완벽한 데이터 명세는 아니다. 생성 이미지에서 남는 아이콘·장비 그림·패널 치수 차이는 구현 시 공통 자산과 실제 데이터로 통일한다. 현재 키보드 행동은 Space이며 시안의 F와 별도 방해 버튼은 개편 제안이다.

별도 기능 수정은 실제 코드에 적용했다: 인물 실제 경계 기반 아틀라스 등록, 이동 취소 미끼 1회 반환, 다리 양쪽 충돌 틈 연결. 로컬 검증 결과는 docs/verification.md 참고. 신규 디자인/맵 확대는 검토 후 구현할 대상으로 남아 있으며 이번 작업에서 운영 배포하지 않았다.
