# 하늘색·파란색 색감 수정안

2026-11-26 사용자 요청에 따라 기존 청록색을 하늘색과 파란색으로 바꾼 화면별 시안이다. 내장 ImageGen으로 각 원본 이미지를 수정한다. 기존 청록색 시안은 ../2026-11-25-fishing-ground 에 보존한다.

- 물: 얕은 곳 하늘색, 중간 파란색, 깊은 곳 진한 파랑
- 버튼: 하늘색 하이라이트가 있는 파란색
- 패널: 청록 기운을 뺀 남청색
- 숲·목재·캐릭터·물고기의 원래 색과 화면 구성 유지
- 네온 테두리·부제·불필요한 설명 추가 없음

13개 화면은 동일한 디자인 방향의 묶음이다. 생성 이미지의 작은 글자/아이콘 차이가 있을 수 있으며, 실제 구현에서는 공통 자산과 서버 데이터로 연결해야 한다. 시안 제작 당시에는 색감 수정 이미지였으며, 2026-11-26 후속 작업에서 로컬 게임의 실제 화면과 낚시터로 구현했다. 운영 배포 여부는 프로젝트 루트의 design-qa.md와 docs/verification.md를 기준으로 확인한다.

각 화면의 입력 이미지 경로·색상·프롬프트는 prompts.json 에 기록한다. index.html 을 열어 전체 화면을 볼 수 있다.
