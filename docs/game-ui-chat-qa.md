# 2026-11-26 게임 UI 및 채팅 검수

가방은 지퍼 프레임, 상점은 어닝과 진열대, 순위는 리본, 재화는 칩, 미니맵은 종이 모서리로 역할을 구분했다. 우측 하단 동작은 56×56px 네 칸이며 C/F/Space/I를 칸 안에 표시한다. 그림은 36×36px, 가로 중심 오차 0px이고 키 영역을 위해 위로 3px 배치했다. 채팅은 생성 이미지 버튼으로만 열며 X와 Esc로 닫는다.

실제 Inventory 컴포넌트에 검수용 데이터를 전달하는 로컬 fixture에서 가방 5개 탭과 상점 3개 탭을 확인했다. 구매 검증으로 세지 않는다. Chrome 1920×776과 1280×720에서 10개 화면 상태의 중앙 정렬 대상 114항목을 검사해 가로 최대 0px/세로 최대 0.25px, 가로 넘침 0건을 확인했다. DOM 내용/패딩 중심을 측정했다. 상점 미끼 상품명은 가격과 함께 왼쪽 정렬하는 항목이라 중심 검사에서 제외했다. 장착 버튼이 세로로 잘리는 문제를 수정했다. 긴 목록은 스크롤한다. 증거: output/game-areas-qa/alignment.json, bag-final.jpg, shop-final.jpg.

Chrome localhost와 IAB 127.0.0.1의 서로 다른 서버 세션으로 메시지를 주고받았다. 두 로그에 동일한 이름/본문이 나타났고 두 캐릭터 위 말풍선을 직접 확인했다. 입력 중 방향키로 미니맵 위치가 바뀌지 않았고 X/Esc 닫기 및 닫힌 상태 Enter가 채팅을 열지 않는 것을 확인했다. 증거: game-chat-final.jpg, compact-hud-final.jpg, quick-proof.json.

채팅 본문은 영속 저장하지 않는다. 서버가 ID/이름/시각을 확정하고 전송 간격만 기존 SQLite 테이블에 저장한다. 최근 40개를 메모리에 두고 창에는 최근 4개를 표시한다. 말풍선은 6초, 마지막 0.7초에 사라진다. 서버 테스트는 정규화/길이 제한/이름 위조 거절, 전체 전파, 재접속 후 전송 간격 유지와 인벤토리 불변을 포함한다. 타입/빌드/이미지 검사 및 테스트 43개 통과.
