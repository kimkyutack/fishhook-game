# 외형 비율·방향 교정 (2026-11-27)

## 원인과 수정

기존 외형은 큰 초상화를 참조해 별도로 생성되어 기본 캐릭터보다 머리가 작고 몸이 길었으며 카메라 각도도 달랐다. 모자를 포함한 전체 높이를 같은 값으로 축소해 산타·오리 외형의 실제 몸이 작아지는 문제도 있었다.

- 기본 캐릭터의 실제 이동·낚시·액션 프레임을 참조 시트 6장으로 추출했다. 이 프레임의 짧은 몸, 큰 머리, 각 방향의 포즈를 유지하도록 의상만 편집하는 이미지 생성 18장을 제작했다. 남녀 × 외형 3종 × 120프레임, 총 720프레임이다.
- 기본 프레임 192px/발 y=180에 대응하는 외형 프레임은 224px/발 y=210이다. 같은 256/192 월드 배율을 유지하고 투명 여백에 모자를 넣는다. 오리·산타 모자에는 12px 높이를 허용하며 회사원은 추가 높이가 없다.
- 같은 시트·방향 내 프레임은 고정된 가로·세로 배율을 공유한다. 머리 중심과 발 위치를 기본 프레임에 맞추고 눕는 포즈도 기본 중심을 따른다. Sharp 리사이즈는 지정한 크기를 보존하도록 `fit: "fill"`을 사용한다.
- 외형 방향 선택을 기본 캐릭터의 `locomotionPose`와 공유한다. 발차기·도주가 이전 대각선 방향을 따라가는 불일치를 제거했다.
- 걷다 멈춘 경우 외형 교체 전의 걷기 방향과 정지 프레임 진행률을 유지한다. 대각선 뒷모습에서 장착만으로 옆모습 대기로 바뀌지 않는다.
- 투명 여백 때문에 캐릭터 클릭 영역이 커지지 않도록 기존 192px 영역과 발 기준점을 유지한다.

## 검증

- `npm test`: 11개 파일, 75개 테스트 통과. 기본·외형의 대각선 이동/낚시/발차기/도주 방향과 발 기준점 계약을 추가 검사했다.
- `npm run assets:check`: 외형 720프레임이 비어 있지 않고 가장자리 잘림이 없음을 검사했다. 6개 아틀라스는 1792×3360, 초상화 6개는 알파가 있는 384×384다. 각 방향의 서 있는 기준 포즈 머리 폭은 기본 대비 3px 이내, 발 위치·기준 높이는 1px 이내다. 이 수치는 모든 애니메이션 포즈의 픽셀 일치를 의미하지 않는다.
- `npm run build`: 통과.
- 로컬 Chrome 남자와 인앱 브라우저 여자에서 외형 3종 장착, 기본 복귀, 상대 미니맵 반영을 확인했다. 같은 위치에서 남자 기본/산타 전후, 여자 대각선 이동 정지 후 기본/산타 전후를 직접 비교했다. 걷다 멈춘 뒷모습·발 포즈가 유지된다. 앉기·낚시도 직접 확인했으며 런타임 오류가 없었다.
- 최종 이미지 재등록 이후 실제 화면 증거: `output/costume-fit-qa/right-comparison.png`, `output/costume-fit-qa/diagonal-comparison.png` (검증 산출물, Git 제외).
- 기존 외형 ID·가격·구매 기록·서버 규칙은 변경하지 않는다. 운영 테스트 캐릭터는 만들지 않았다.

## 재생성

1. 기본 이미지 참조가 필요하면 `node --import tsx scripts/prepare-costume-references.ts`.
2. 이미지 편집 프롬프트: `art/prompts/costume-fit-v2.json`. 생성 원본: `art/source/costumes/v2/`.
3. `npm run assets:pack:costumes`로 아틀라스·초상화·등록 manifest를 만들고 `npm run assets:check`로 검사한다.

AI로 편집한 그림이므로 모든 픽셀·모든 세부 형태가 기본과 동일하지는 않다. 기본 프레임의 카메라·비율·발 기준을 공유하도록 교정하고 실제 장착 전후를 확인했다.
