# 북쪽 통로 수정 및 검증 — 2026-11-26

## 변경 범위

`src/config/map.ts`의 지형 중심선과 `WorldScene.ts`의 클릭 이동 경로 추종을 수정했다. 기존 맵 이미지, HUD, 서버 명령과 이동 속도는 변경하지 않았다.

- 왼쪽 위 강변의 실제 그림과 어긋난 중간 굽이를 다시 따라가도록 `west-bank` 중심선을 보정했다.
- 오른쪽 위 지도에 그려져 있지만 통행 영역이 없던 숲길 갈림길을 `north-east-trail`로 연결했다.
- 강변에서 작은 강 부두로 들어가는 입구를 강변 중심선과 직접 연결했다.
- 상점 위 산책로가 건물의 오른쪽 위 모서리를 관통하던 구간에 우회 지점을 추가했다. 건물 충돌을 지우거나 물 위를 개방하지 않았다.
- 브라우저에서 오른쪽 숲길로 클릭 이동할 때 목표보다 86월드 단위 앞에서 멈추는 문제를 재현했다. 길의 각도와 무관하게 8방향으로 조종하던 코드가 경로를 잘라 이동 영역 가장자리에 걸렸다. `navigation.ts`의 `RouteSteering`이 각 구간의 실제 각도를 따라가도록 수정했다. 한 구간의 방향을 유지해 매 프레임 입력이 미세하게 달라지며 전송 제한을 넘지 않도록 했다.

## 자동 검증

새 `tests/north-map.test.ts`는 실제 그림의 강변/숲길 지점, 물 진입 거절, 모든 작성된 통로의 양방향 구간 이동, 북쪽 8개 분기/부두의 왕복 경로, 상점 모서리 우회를 검사한다. 이동은 22월드 단위씩 반복해 끝점까지 도달하는지 확인한다.

- 전체 테스트: 7개 파일, 54개 통과.
- 타입 검사 및 빌드: 별도 로컬 복사본에서 통과.
- 테스트 데이터는 운영과 메인 작업에서 분리한 로컬 복사본을 사용했다.
- 배포/커밋/푸시는 이 작업에서 수행하지 않았다.

그림과 중심선 비교 및 실제 브라우저 이동 증거는 `output/north-map-qa/`에 있다. 이 경로는 검수용 로컬 파일이며 배포 이미지에 포함되지 않는다.

브라우저 확인: 별도 로컬 Worker8824에서 강변을 방향키로 통과하고, 북쪽 다리→오른쪽 해안→새 숲길 끝으로 클릭 이동했다. 수정 전 실제 멈춤 위치(4116.9,537.65)를 회귀 검사에 넣었고 수정 후 목표(4168,468)의 종료 허용 거리16 안까지 도달했다. 북쪽 8개 분기/부두 왕복, 전체16개 통로104개 구간의 양방향 이동을 자동 검사한다. 낚시 지점50개를 유지한다.
