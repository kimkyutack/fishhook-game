# 매일 미끼 지급

- 한국시간 매일09:00(UTC00:00)에 기본 미끼 지렁이20개를 추가한다. 유료 미끼는 지급하지 않는다.
- 신규 계정은 최초 미끼20개를 유지하고 다음09:00부터 받는다. 기존 계정은 기능 적용 시점에 기준일을 만들며 과거 가입일부터 소급하지 않는다.
- 접속 여부와 관계없이 누적한다. 지연·오프라인 기간에 지난 지급일이3번이면60개를 추가한다.
- SQLite의 daily_bait_grants에 마지막 지급 기간을 기록하고 수량과 기간을 하나의 트랜잭션으로 갱신한다. 알람 재시도·재접속·DO 재초기화로 중복 지급되지 않는다.
- 기존 낚시 완료 시각과 다음 지급일 중 빠른 시각을 단일DO 알람에 예약한다. 알람 뒤에는 접속자에게 갱신된 수량을 전송한다. 알람이 지연돼도 다음 요청에서 지난 지급분을 처리한다.
- 가방과 상점의 미끼 탭에 지급 시각·대상·오프라인 누적 안내를 표시한다.

검증: tests/daily-bait.test.ts의09시 경계·시작 지급·중복 방지·오프라인 누적·기존 계정 초기화·실시간 알람 갱신·낚시 알람 우선순위7개 통과. 별도 배포는 수행하지 않았다.

전체 회귀 검사에서는61개 중54개 통과/7개 실패였다. 실패는 tests/world.test.ts의 물가 방향을 맞추지 않은 기존 cast fixture6개와 tests/movement.test.ts의 idle 대각선 기대값1개다. 실제 fishingAim에서 해당 fixture의 left방향은false/down방향은true이며, locomotionPose의 idle결과는down_right로 확인했다. 이 대화의 범위를 넘어서는 진행 중 변경은 수정하지 않았다. 지급 관련7개와 타입 검사는 통과했으나 전체 검사 통과로 보고하지 않는다.
