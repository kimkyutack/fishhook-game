# 이미지 제작과 검수

## 2026-11-26 대각선 걷기 추가

실제 ImageGen으로 기존 남녀 캐릭터를 참조한 대각선 걷기 원본2장과 투명 배경 정리본을 제작했다. 각각1536×1024/6열2행/12프레임이며 위는 우하단, 아래는 우상단이다. 왼쪽 방향은 동일 프레임 좌우 반전이다. 원본의 인물 경계를 추출해 고정 머리 중심/발 기준선180px, 성별 공통 배율로 192px 프레임에 패킹했다. 런타임은1152×384 투명 PNG2장이다. 프롬프트/경로는 `art/prompts/diagonal-walk.json`, 재패킹은 `npm run assets:pack:diagonal`이다.

전체24개 새 프레임의 실제 알파·프레임 경계 유입·해시를 검사하고 `art/references/diagonal-walk-registered-review.png`를 육안 확인했다. 최종 빌드의 남녀 좌하단 걷기를 실제 두 브라우저에서 움직이는 중 캡처했다. 우상단 남자 프레임도 캡처했으며 모든 프레임의 실시간 브라우저 육안 검수를 했다는 뜻은 아니다. 미니맵은 기존 전체 지형/초상화/상점/찌 이미지를 재사용한다. 현재 추가/교체 논리 자산은35개, 실제 사용 캐릭터 프레임은 기존312+신규24=336개다. 아래33개/312개 기록은 이 추가 전 단계의 수치다.

## 2026-11-26 하늘색·파란색 구현

선택한 기준은 design/2026-11-26-sky-blue의 13장이다. 런타임 텍스트와 실제 플레이어는 배경에 구워 넣지 않았다. ImageGen으로 배경, 남녀 정면 이미지, 발판, 로고, 패널, 버튼, 장비/미끼 아이콘, 왕관/메달을 생성·분리했다. 새 논리 이미지 자산은 33개이며 실제 원본과 PNG/WebP 변형의 크기·해시는 art/redesign-manifest.json에 있다. 환경 PNG와 WebP를 중복 제작 수로 세지 않는다. 글꼴은 OFL 라이선스의 Noto Sans KR이다.

전체 지형 원본은 1536×1024, 고해상도 사분면 4장은 각각1536×1024다. 사분면의 접합선에 기하 차이가 있어 각 타일 경계64원본픽셀만 일관된 전체 원본과 알파 혼합한다. 나머지 영역은 고해상도 지형을 유지한다. 전체 월드6144×4096은 게임 좌표 크기이며 같은 해상도의 원화를 생성했다는 뜻이 아니다. 원경 장식으로 끊긴 동쪽 일부 부두는 이동 가능한 길에 포함하지 않았다.

어종 원본50종은 기존 귀여운 원화를 유지하고 투명 여백을 제거한 후 비율을 유지해 최대256px로 패킹한다. 고정 정사각형 여백 때문에 물고기가 카드 안에서 작게 보이던 문제를 교정했다. 캐릭터 패킹의 접지 root는 (0.5,0.9375)로 실제 발 기준선180/192에 맞춘다. 전체320셀의 인접 머리 유입 검사와 사용312프레임 연결은 assets:check에서 검사한다.

실제 화면 캡처 및 원본과의 합본 비교는 output/design-qa, 결과는 루트 design-qa.md에 기록한다. 아래2026-11-25 기록은 당시 상태이며 후속 구현/패킹 변경은 이 항목을 우선한다.

## 2026-11-25 후속 교정

캐릭터 원본은 정확한 균등 격자가 아니었다. 예를 들어 남자 왼쪽 첫 인물의 불투명 경계는 x=68~203인데 기존 첫 셀 끝은 약198이어서 다음 프레임에 머리 조각이 들어갔다. scripts/character-regions.ts에서 원본의 온전한 인물 연결 영역 40개를 찾고 행/열 순으로 등록한다. 실제 경계를 잘라 같은 192px 캔버스에 머리 중심/발 위치를 맞춘다. 방향별 공통 스케일을 사용하므로 모션별 자동 확대를 하지 않는다. 원본 그림을 재생성하거나 덧그리지 않았다.

8개 시트의 320개 패킹 셀 전체에 대해 프레임 가장자리의 불투명 픽셀 유입을 assets:check로 검사했다. 실제 사용은 기존과 같은312프레임이다. 대표80프레임 합본 art/references/registered-character-review.png에서 인접 머리 조각이 없음을 육안 확인했다. 이번 수정 후 브라우저에서 모든 동작을 다시 재생한 검증은 수행하지 않았다.

새 낚시터와 페이지/모달 디자인은 design/2026-11-25-fishing-ground의 최종13장이다. 내장 ImageGen으로 생성하고 데이터·선택 테두리·물고기 스타일 교정을 수행했다. 이13장은 시안이며 런타임154개 이미지 수에 포함하지 않는다. 새 맵·UI의 실제 구현/운영 반영은 아직 수행하지 않았다.

사용 도구는 내장 `image_gen`이다. 원본은 art/source, 실제 배포 PNG는 public/assets, 규격·프레임·앵커·레이어·ready 상태는 art/manifest.json, 종별/캐릭터별 프롬프트는 art/prompts/asset-prompts.json에 있다. 최종 사용한 원본은 모두 프로젝트 안에 보존한다. 기본 생성 경로에만 의존하지 않는다.

후속 요청에 따라 실사 물고기를 폐기하고 둥근 몸·큰 눈·표정이 있는 캐릭터 물고기로 수정했다. 캐릭터도 원래 2.7등신 대신 짧은 약 2등신으로 만들었다. 남자는 갈색 머리·청록 재킷, 여자는 단발 갈색 머리·코랄 재킷이며 능력치는 같다.

- 런타임 PNG 154개, 약 8.8MiB. `npm run assets:check`가 경로, 실제 크기, 50종의 고유 이미지 해시와 312 캐릭터 프레임 연결을 검사한다.
- 물고기 50개 PNG, 등급별 10종. 색상만 바꾼 복제 파일은 없다. 원본은 등급별 5×2 아틀라스이며 런타임은 256×256이다. 개별 원본 1024×1024 목표에는 미달한다. 이를 1024 원본으로 제작했다고 세지 않는다.
- 캐릭터 8개 아틀라스(남녀×네 방향), 각 39프레임 사용. 원본은 8×5 배열이며 마지막 한 칸은 사용하지 않는다. 고정 캔버스·공통 스케일로 패킹하고 매 프레임 자동 확대를 하지 않는다. 192px 프레임, 접지 root(0.5,0.875), 1px extrusion +1px transparent padding을 사용한다.
- idle·walk·sit_down·seated_idle·cast·fishing_wait·reel_in·kick·run·startled를 연결한다. 위 방향이 정면으로 생성된 첫 결과와 앉아서 차던 프레임을 수정했다. 최종 발차기는 지지발로 서서 몸을 기울이고 다리를 뻗는다.
- 장착 아이콘 낚싯대 3종과 월드용 48개 방향/상태 이미지(3종×4방향×정상·휨·튕김·회수)를 구분한다. 손잡이와 끝 앵커에서 줄 이미지를 연결한다. 뒤를 볼 때 몸 이미지가 낚싯대 앞에 오는 깊이 규칙을 사용한다.
- 의자는 네 방향이며 별도 이미지 레이어다. 바닥·수면·물가·소품·상점 가판 앞뒤·캐릭터·장비·이펙트를 분리한다. NPC는 이미지의 약한 호흡 이동으로 idle을 표현한다.
- 버튼·패널은 래스터 nine-slice이며 글자와 숫자는 실제 텍스트다. 잘린 모서리가 있던 초기 UI 아틀라스 대신 개별 패널·버튼 이미지를 재제작했다. pressed는 정상적인 원본 아틀라스 셀을 사용한다.
- 이펙트는 물결 4, 물보라 4, 충격 4 프레임과 찌·별 이미지의 이동/투명도 연출이다. 수면 타일은 강한 타일 경계가 보였던 초기 결과 대신 차분한 새 이미지를 사용한다.

어종·방향·모션 합본과 실제 게임의 약 96px 표시 크기로 검수했다. 물고기 30종에 남았던 불투명 배경도 이미지 도구로 제거했다. 최종 물고기 50종의 네 모서리 alpha 최댓값은 1/255이다. 임시 이미지와 누락 이미지를 ready로 집계하지 않았다. 생성물의 원본은 수작업 512px 캐릭터 프레임/1024px 개별 어종 원화와 동등한 해상도는 아니다.

미제작 필수 런타임 이미지: 없음. 고해상도 개별 원화와 전문 애니메이터의 추가 미세 보정은 향후 아트 개선 범위다.

## 현대적인 HUD 스킨 후속 교체

금색 리벳/짙은 남색 대신 하늘색·흰색 표면과 파란 말랑한 버튼으로 교체했다. ImageGen 원본은 art/source/modern-hud-skins.png, 제작 브리프는 art/prompts/modern-hud-skins.json, 좌표 기반 재패킹은 scripts/pack-modern-ui.ts다. 실제 생성 스킨4개를 추가해 현재 논리 이미지39개다. 전체 지도와 캐릭터/어종은 유지했다. 최종1920/1280/390 화면에서 육안 검사했으며 순위와 피드의 실제 경계를 측정했다.

## 역할이 다른 캐릭터 선택 UI

사용자의 '모든 텍스트 영역이 같은 상자처럼 보인다'는 후속 요청에 따라 선택 화면만 제목/이름/선택/행동을 구분했다. 제목과 남녀 라벨의 패널을 제거했고, 실제 생성한 천 리본 명찰·원형 뒤로 버튼·체크 배지·산호색 찌 장식 시작 버튼을 연결했다. 기존 캐릭터와 발판/배경을 유지했다. 원본 art/source/selection-game-ui.png(1536×1024), 프롬프트 art/prompts/selection-game-ui.json, 재패킹 scripts/pack-selection-ui.ts. 생성 결과는 균등4칸과 달라 실제 물체 경계를 검수해 좌표로 패킹했다. 논리 자산43개(이전39+신규4)이며 모두 런타임에 연결했다.

명찰은 리본 꼬리/접힘을 제외한 흰 면 중심, 시작 버튼은 찌 장식을 제외한 본체 중심을 기준으로 라벨을 맞췄다. 긴 이름은 말줄임과 전체 이름 title을 사용한다. 캐릭터 선택 체크는 발판 옆에 배치하고 남녀 선택과 함께 이동한다. 새 자산 생성/패킹 외 캐릭터 모션과 게임 규칙은 바꾸지 않았다.
## 2026-11-26 게임 영역과 메시지 이미지

실제 생성 원본 game-area-skins.png에서 역할별 이미지 8개를 분리하고 quick-chat-ui.png에서 메시지/닫기/슬롯 3개를 분리했다. 프롬프트는 art/prompts/game-area-skins.json과 quick-chat-ui.json이다. alpha8 미만의 가장자리 노이즈를 제거했으며 scripts/pack-game-area-ui.ts와 pack-quick-ui.ts로 재현한다. 기존 아이콘 12개는 그림 경계를 96px 캔버스 중앙에 맞춘 변형이며 pack-quick-icons.ts에서 만든다. 새 AI 생성으로 세지 않는다. 총 66개 논리 자산은 생성 54개와 정렬 변형 12개다. 배 모양 dock은 작은 퀵슬롯 요청에 따라 사용하지 않으며 manifest에 used:false로 기록했다. 실제 연결한 프레임/아이콘/말풍선은 게임과 가방/상점 8개 탭에서 확인했다.
